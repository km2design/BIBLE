# 光道 · 四福音繪卷

手機優先的聖經動漫故事 App 原型：一邊看繪卷場景，一邊讀經文，伴隨背景音樂與靈修。

## 功能

- **繪卷播放**：十二卷耶穌生平精選（四福音）
- **經文同步**：每一幕對應和合本經文，可在「故事／經文」之間切換
- **音效設定**：右上角開關＋設定頁；10 種柔和背景純音樂、動畫音效、大自然環境聲（風／鳥／水滴／森林／海邊等），可分別調音量
- **靈修**：每卷結束後的默想與簡短禱告；另有「今日靈修」頁

## 開發

```bash
npm install
npm run dev
```

```bash
npm run build
```

## 技術

- Vite + React + TypeScript
- React Router（首頁／目錄／播放／靈修）
- Web Audio API 背景音樂

經文採用公開流傳的和合本譯文作靈修用途示範。視覺為原創氛圍繪卷場景（非授權商業動漫素材）。
